# Erotanatichemistry
Experimental repository for new psychoactive substances, adding my G. Bataille´ based treatments for its pathological use, using programed resources that will be stored here.

## Autorização / Access

Se a dúvida for "como autorizo a DrSiky no Erotanatichemistry?", isso não é feito por código deste repositório.

No GitHub, a autorização de acesso é feita em **Settings → Collaborators and teams** do repositório:

1. Abra o repositório `DrSiky/Erotanatichemistry`.
2. Vá em **Settings**.
3. Abra **Collaborators and teams**.
4. Clique em **Add people**.
5. Procure por `DrSiky` e envie o convite com o nível de acesso desejado.

Se `DrSiky` já for o proprietário da conta ou da organização, nenhuma autorização adicional é necessária.
